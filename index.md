# RVLS Rota Backup

RVLS Rota Backup is a private utility developed to support the automated duty rota system operated by Ribble Valley Live Steamers (RVLS).

## Purpose

The application creates backups of the rota system's configuration, database and supporting files to help recover the system following equipment failure or accidental data loss.

## Google Drive Access

The application uses Google Drive with the account holder's permission to store and manage its backup files.

It is intended for use by the authorised system administrator, not the general public.

## Privacy

The application does not sell personal information or use Google account data for advertising.

For details, see the application's privacy policy.
